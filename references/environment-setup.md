# 环境准备

仅在环境缺失或版本不兼容时读取并执行本流程。

## 检测

1. 检测 Windows 架构、剩余磁盘空间、Node.js 和 npm。
2. 从项目元数据、编辑器配置和构建记录识别 Creator 精确版本。
3. 检测 Cocos Dashboard、对应 Creator 版本和微信开发者工具。
4. 检测 Cocos Dashboard 是否已经登录，只记录登录状态，不读取账号详情或登录凭证。
5. 已有兼容环境时复用，不重复安装，不自动升级项目。

## Cocos 账号注册与登录

如果 Cocos Dashboard 要求登录，先询问用户是否已有 Cocos 账号：

- 已有账号：打开 Dashboard 的官方登录界面，让用户本人完成登录。
- 没有账号：打开 Cocos 官方注册入口，逐步指出需要填写的字段，引导用户本人完成注册、验证和首次登录。
- 忘记密码：只使用官方找回密码入口，引导用户本人完成重置。

注册或登录过程中，用户名、手机号、邮箱、密码、短信/邮件验证码、图形验证码、身份信息和恢复代码均由用户本人输入。不要要求用户在聊天中发送这些内容，不要代填密码或验证码，不要截图、记录、转述或保存登录凭证。服务条款、隐私政策和营销订阅由用户自行阅读并选择，不能代替用户同意。

页面结构或注册链接发生变化时，从 Cocos 官方网站或 Dashboard 内的官方入口重新定位，不使用搜索广告、第三方代注册、共享账号或非官方登录页面。注册完成后回到 Dashboard，确认显示为已登录，再继续安装对应 Creator 版本。

## 安装授权

软件安装属于系统级变更。安装前向用户展示名称、版本、官方来源、安装路径以及是否需要管理员权限，并取得“确认安装”。只从 Cocos 和微信官方渠道获取安装包，禁止第三方镜像、破解版和捆绑包。

Creator 优先通过 Cocos Dashboard 安装与项目匹配的版本。精确版本不可用时停止并说明迁移风险；不要用新版本打开并保存项目来碰运气。

不要自动卸载旧版本、修改系统 PATH、接受许可协议或绕过 UAC。许可协议由用户确认；UAC 弹窗提示用户点击“是”。微信开发者工具登录由用户扫码完成，不保存登录凭证。

## 验证

- Creator 能启动并打开项目，且没有触发项目升级。
- 需要账号时，用户已完成 Cocos 官方注册并登录 Dashboard。
- 微信开发者工具能启动。
- Creator 中配置了微信开发者工具的绝对路径。
- 用户已扫码登录正确账号。
- 同一安装错误最多重试三次；仍失败时保留现场并给出一个明确的用户操作。
